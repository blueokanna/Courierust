# 快速上手

本页用一个 5 分钟跑通的例子带你建立客户端 + 服务器。所有代码都是真实可运行的 API 用法，没有伪代码。

## 1. 添加依赖

```toml
[dependencies]
courierust = "0.1"
```

默认开启 `std` feature，包含客户端、服务器、线程池和 gRPC。如果只需要 `no_std` 协议核心，见 [no_std 使用](no_std-使用)。

## 2. 一个文件同时跑服务器和客户端

把下面的代码存成 `examples/hello.rs`：

```rust
use courierust::body::Body;
use courierust::client::{Client, ClientConfig};
use courierust::http::request::Request;
use courierust::http::response::Response;
use courierust::server::{Server, ServerConfig};

fn main() -> courierust::Result<()> {
    // --- 服务器 ---
    // http2 = true 表示同一个端口同时服务 h2c 和 HTTP/1.1。
    let server_cfg = ServerConfig {
        http2: true,
        ..Default::default()
    };
    let server = Server::bind_with_config("127.0.0.1:0", server_cfg)?;
    let addr = server.local_addr()?;

    // serve_background 返回句柄，服务器在后台持续运行；
    // 下面的客户端可以立刻访问它。
    let _handle = server.serve_background(|req: Request<Body>| -> Response<Body> {
        let mut resp = Response::with_status(200.into());
        resp.headers.insert(
            courierust::http::header::HeaderName::from_lowercase("content-type"),
            courierust::http::header::HeaderValue::from_static("text/plain"),
        );
        let body = req.body.collect().unwrap_or_default();
        resp.body = Body::Bytes(body);
        resp
    })?;

    // --- 客户端 ---
    let client_cfg = ClientConfig {
        http2: true,
        ..Default::default()
    };
    let client = Client::with_config(client_cfg);

    let resp = client.get(&format!("http://{addr}/hello"))?;
    println!("GET  -> {} {}", resp.status.as_u16(), resp.body.collect()?.to_str()?);

    let resp = client.post(&format!("http://{addr}/echo"), "hello from client")?;
    println!("POST -> {} {}", resp.status.as_u16(), resp.body.collect()?.to_str()?);

    Ok(())
}
```

运行：

```bash
cargo run --example hello
```

预期输出（端口随机）：

```
GET  -> 200 hello
POST -> 200 hello from client
```

## 刚才发生了什么

- `Server::bind_with_config("127.0.0.1:0", ...)` 绑定随机空闲端口；`local_addr()` 告诉你实际端口。
- handler 就是一个普通闭包 `Fn(Request<Body>) -> Response<Body>`，这里把收到的请求体原样回显。
- `Client::with_config` 配 `http2: true` 即用 h2c（TCP 直连的 HTTP/2 前导知识），不涉及 TLS。
- `Response::with_status(200.into())` 构造空 200 响应，再按需填 `.headers` 和 `.body`。
