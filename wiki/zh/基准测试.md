# 基准测试

`benches/` 工作区提供三个以 release profile 运行的可执行套件：

- `throughput`：Courierust 的 HTTP/1.1 keep-alive、并行 HTTP/1.1、h2c 多路复用，以及 HTTPS + HTTP/2。
- `compare`：与 hyper、reqwest 的配对 loopback 对比。
- `interop`：针对 hyper、hyper-util、reqwest 的协议兼容性验证；它不是性能基准。

运行与 GitHub Actions 相同的套件：

```bash
cargo bench --manifest-path benches/Cargo.toml --locked --bench throughput
cargo bench --manifest-path benches/Cargo.toml --locked --bench compare
cargo bench --manifest-path benches/Cargo.toml --locked --bench interop
```

基准 profile 使用 thin LTO 和单个代码生成单元。任一协议错误或断言失败都会使对应 suite 以非零状态退出。GitHub Actions 为每个 suite 分别保存日志，在运行摘要中发布结构化报告，并上传报告和原始日志。

## 吞吐基准

`throughput` 测量 loopback 上完整的请求/响应往返。每个请求都会校验状态并完整消费响应体后才计入结果。适用场景覆盖空响应、1 KiB 和 64 KiB 响应。

| 用例族 | 传输 | 负载 |
| --- | --- | --- |
| `h1_sequential` | HTTP/1.1 | 单个 keep-alive 客户端连接 |
| `h1_parallel_w*` | HTTP/1.1 | 1、4、8 个 worker 的独立客户端 |
| `h2_multiplex_w*` | h2c prior knowledge | 一个池化 HTTP/2 连接，1、8、32 个 worker |
| `https_h2_sequential` | TLS 1.3 + HTTP/2 | 证书验证、ALPN 与加密请求/响应路径 |

每条结果记录 RPS、响应吞吐量、P50/P75/P90/P95/P99 请求延迟和实际服务端线程数。可使用 `BENCH_REQUESTS` 和 `BENCH_SERVER_THREADS` 覆盖默认请求数与服务端 worker 数。HTTP/1.1 并行用例会把实际服务端线程数提升到至少客户端 worker 数，因为 Linux 的阻塞式服务端模型会为每条空闲 keep-alive 连接占用一个 worker。

## 跨库对比

`compare` 在测量一侧时固定另一侧的 peer：

- 客户端对比：Courierust 与 reqwest 客户端连接同一个 hyper 服务端。
- 服务端对比：同一个 reqwest 客户端分别连接 Courierust 和 hyper 服务端。
- 协议：HTTP/1.1 与 h2c prior knowledge。
- 负载：1 KiB、64 KiB 的顺序响应，以及 8 worker 的 1 KiB 客户端并发负载。
- 每次测量均会完整消费并校验响应体。

每个配置均运行偶数轮，并在每轮交替执行顺序，确保任一实现不会总是先测量。输出结果合并所有轮次，并包含实际重复次数。可用 `BENCH_REPETITIONS`、`BENCH_REQUESTS`、`BENCH_PARALLEL_REQUESTS` 和 `BENCH_COMPARE_WORKERS` 调整负载。若设置奇数轮，程序会向上取整为偶数轮，以保证执行顺序平衡。

`raw_tcp_floor` 仅是四字节 echo 的传输层参考值，不是 HTTP 对比行，也不能据此宣称 HTTP 性能比例。基准不再发布进程级分配次数，因为服务端线程、运行时、日志和 harness 自身的分配无法归因到某一个客户端或服务端实现。

## 解读结果

结果以 `RESULT|...` 记录输出，便于机器解析，包含协议、负载、客户端 worker 数、服务端线程数、请求数、RPS、响应 MB/s、分位延迟和样本数。只比较协议、负载、worker 数、服务端线程数及测量层相同的行。loopback 数据会受到 runner CPU 配额、内核调度和后台负载影响，应只用于同一 runner 上的受控对比，不能作为通用性能结论。

`interop` 输出 `INTEROP|...` 记录。任何失败或超时都是兼容性回归，会使 CI 失败，与性能数值无关。
